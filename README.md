# Car Rental Management API


## 1. About the project

> This is a node.js and express based REST API that sereves as the backend for a vehicle management system.

---


## 2. Used Technologies

 Node.js
 Express.js
 MySQL
 JWT
 Git

## 3. Contributors

This is an independently developed project. 

## 4. Features

User authentication with login and registration
Role-based authentication for protected API routes
CRUD operations

## 5. How to install 

### 5.1 How to get the project

1. Clone the repository 
2. On Your computer: 
    npm install
3. Install mysql Workbench on your maschine
4. Import .sql file from db_dump folder to Mysql workbench DBMS.

### 5.2 Start the project

type npm start
