# Car Rental Management API


## 1. About the project

This is a node.js and express based REST API that sereves as the backend for a vehicle management system.

## 2. Used Technologies

    - Node.js
    - Express.js
    - MySQL
    - JWT
    - Git

## 3. Contributors

This is an independently developed project. 

## 4. Features

    - User authentication with login and registration
    - Role-based authentication for protected API routes
    - CRUD operations

## 5. How to install 

### 5.1 Download the project

    ```bash
    npm install
    npm start
    ```


## 6. Neccecary Environment Variables
Az adminisztrátoroknak lehetőséget kell biztosítani új felhasználók hozzáadására, meglévő felhasználók módosítására és törlésére.
A felhasználók adatait biztonságosan kell tárolni és kezelni.

## 7. Database
Az alkalmazásnak intuitív és felhasználóbarát felhasználói felülettel kell rendelkeznie.
A felhasználóknak könnyen hozzáférhető navigációs rendszerrel kell rendelkezniük a funkciókhoz és menükhöz.
