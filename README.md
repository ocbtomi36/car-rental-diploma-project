# Car Rental Management API


## 1. About the project

This is a node.js and express based REST API that sereves as the backend for a vehicle management system.

---


## 2. Used Technologies

 * Node.js
 * Express.js
 * MySQL
 * JWT
 * Git

## 3. Contributors

This is an independently developed project. 

## 4. Features

 * User authentication with login and registration
 * Role-based authentication for protected API routes
 * CRUD operations for each objects

## 5. Getting Started 

### 5.1 Must have on your computer

 * Node.js version 17 or higher
 * MySQL Server 8.0+ or MariaDB 10.5+
 * MySQL Workbench 8.0 CE (recommended graphical client)
 * Git or another Git-compatible version control tool

### 5.2 How to get the project

1. Clone the repository on your local maschine

```bash
HTTPS: https://github.com/ocbtomi36/car-rental-diploma-project.git 
```
or 
```bash
GitHub_CLI: gh repo clone ocbtomi36/car-rental-diploma-project
```

2. On Your computer: 
    npm install
3. Import .sql file from db_dump folder to Mysql workbench DBMS.

### 5.3 Start the project

type npm start
